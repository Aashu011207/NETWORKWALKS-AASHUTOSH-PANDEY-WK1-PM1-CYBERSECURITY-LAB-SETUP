## My Cybersecurity Lab Setup Journey | Week 1 – Networkwalks

This project has been a great learning experience for me. I learned several important things about Kali Linux, networking, and setting up a virtual cybersecurity lab. As a BTech student interested in cybersecurity, I believe these skills will be valuable throughout my learning journey and future career.

During this project, I learned how to:

- Install and configure Oracle VirtualBox.
- Set up a Kali Linux virtual machine.
- Understand the basics of virtualization and how virtual machines work.
- Configure a NAT Network in VirtualBox.
- Learn how IP addresses, subnets, gateways, and network connections work.
- Check network interfaces and IP configuration using Linux commands.
- Understand how Kali Linux connects to the internet through a virtual network.
- Take screenshots to document my practical work and maintain project documentation on GitHub.

One of the most valuable parts of this project was understanding networking practically instead of just learning the concepts theoretically. I also learned how to troubleshoot setup issues and configure my virtual environment.

I have uploaded my project documentation and screenshots to my GitHub repository to record my progress and share what I have learned.

This is just the beginning of my cybersecurity journey. I look forward to learning more about Linux, networking, ethical hacking, and system security through hands-on projects.
